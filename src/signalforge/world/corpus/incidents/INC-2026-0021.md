## Summary
A partner integration received HTTP 429 for 40 minutes after a rate-limit configuration change.

## Timeline
- 15:00 `ratelimit.anonymous_limit` lowered and the matcher changed.
- 15:05 partner reported failures; `gateway-429-ratio` fired.
- 15:40 configuration reverted.

## Root cause
The new matcher classified requests with a partner API key as anonymous.

## Remediation
- Rate-limit changes now require a canary against partner traffic.

## Lessons
- With flat traffic, a 429 spike is configuration.
