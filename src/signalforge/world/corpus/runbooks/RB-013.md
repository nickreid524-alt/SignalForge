Pricing evaluates a rule set against each cart. Evaluation cost grows with the number of active rules, and rule sets are swapped by configuration when campaigns launch.

## Symptoms
- Pricing `latency_p95` jumps at a precise time; `cpu_utilization` roughly doubles.
- Callers (checkout, cart) show elevated `dependency_latency_p95` for pricing.
- WARN logs `rule evaluation slow`.

## Diagnosis
1. Check configuration changes on pricing for `rules.active_set`. Note the rule count in the new set.
2. Confirm callers' `dependency_latency_p95` for pricing rose at the same minute.
3. Deployments on unrelated services (identity, notifications) at similar times are coincidences; verify their own latency is flat before considering them.

## Remediation
- Revert to the previous rule set or prune the campaign rules, then re-launch with rule compilation enabled.
